## 콘셉트 대비
- 0초: 구름 위로 솟은 담장 + 고개 젖힌 놀란 얼굴, 글자 3개(제목·카운터 2,048m·칩 힌트 10회). 최종 숫자·우주·카페·직원·모니터 없음. 배지는 1.2초부터.
- 0.8~1.1 되감기(2,048→2m, 0회), 1.1~1.9 양손 허리, 1.9 손바닥 꾹, 2.08 첫 2배(4m), 팝1 2.2~3.4.
- 힌트 결과 시각: 1~8회 2.08~5.57 / 9·10회 6.2·6.6(구름 돌파, 숫자로만) / 6.8~7.8 경비원 쌍안경·7.2초 모자 벗겨짐(2,048m·10회 고정) / 11~15회 7.8~9.4 비행기 회피 / 16~19회 9.4~10.8 버튼 클로즈업 / 20회 11.0초 누름 → 11.1초 2,097,152m / 12.0 우주 배경(지구) / 13.4 휙 빠지며 방탈출 카페(합판 담장 2m, 카페 벽 빨간 힌트 버튼, 꺼진 모니터) / 13.6~13.85 털썩 / 팝2 13.5~15.1 / 15.2 모니터 '탈출 실패' / 15.3~15.75 직원 고개 까딱 / 15.6~16.9 주인공 눈동자 → 카페 힌트 버튼, 16.9~17.25 직원과 눈 마주침 / 18.0~19.5 엔딩 카드.
- 손: 주인공 손은 손가락 없는 둥근 손, 누를 때는 납작한 손바닥 전체로 버튼 면을 덮음. 경비원은 양손으로 쌍안경만, 직원은 팔 내림. 손가락 세우는 모양 없음.
- 엔딩: '탈출카페' 간판 + 만약에 EP05 + '방탈출 가면 힌트부터 / 찾는 친구한테 보내기' + '다음 만약에는 수요일 저녁 7시'(월요일 게시 → 수요일).

## 내레이션(Cartesia sonic-3.5, Minho, speed 1.18)
- s1 0.00~1.76 / s2 2.40~4.82 / s3 11.10~12.96(atempo 1.1, '우주야' ≈ 12.4~12.9로 12.0초 우주 컷 위) / s4 13.60~16.19 / s5 16.80~18.37
- 자막: s1은 1.1~1.9(0~1.1초는 콜드 오픈 얼굴과 겹쳐 생략), s2·s4는 같은 말의 팝1·팝2가 떠 있어 생략, s3 11.1~12.96, s5 16.8~18.0. 자막 구간 주인공 얼굴은 자막 위(머리 중심 y 445~477).
- 제목·배지는 13.4초 반전 컷부터 숨김(카페 네온 간판과 겹침 방지), 카운터도 반전부터 숨김.

## 사운드
- 피치카토 BGM 120bpm(0~0.8, 1.1~5.8) → 150bpm(5.8~12.5) → 12.5~13.4 정적 0.9초 → 110bpm 카페. 효과음: 버튼 딸깍·담장 쿵(1~8회), 구름 돌파 쿠구궁, 모자 퐁, 비행기 휘익, 20번째 쾅, 우주 반짝, 반전 휙, 털썩, 엔딩 띵. 15.2~18.0 효과음 없음(콘셉트). 내레이션 구간 BGM 0.3배.

- 4~5.8초 아래에서 올려다보는 컷은 주인공 얼굴이 화면 아래쪽(y 약 770~890)에 걸침.
