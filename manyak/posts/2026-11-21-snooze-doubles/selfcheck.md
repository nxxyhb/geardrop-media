## 배치 원칙 (video #2 반려 반영의 바탕)
- 팝 텍스트: CSS top 440(1080 기준 y 880, concept 배치표). 팝 글자 아래 끝 ≈ CSS 490.
- 모든 장면에서 얼굴 윗면·폰 위 끝을 CSS y 520 이상(팝 아래 끝 + 30px)으로 내리고, 자막(top 640) 위로 '5분만 더' 버튼·손끝이 30px 이상 떨어지게 카메라와 소품을 다시 배치.
  - 폰은 침대 발치 앞 작은 협탁 위로 옮김(폰 위 끝 ≈ y 545, 버튼 ≈ y 585~605, 손끝 ≈ 610). 폰 화면 배치도 바꿈: 위 줄 종 아이콘 + 시각, 그 아래 버튼, 나머지는 글자 없는 달·별 배경.
  - 주인공은 베개에서 조금 앞쪽·낮게(머리 윗면 ≈ y 515~520, 폰 왼쪽).
  - 앉은 장면(11~16.6)은 먼 망원 구도로 머리 윗면 ≈ y 530~540, 턱 ≈ 630.

## video #2 반려 fixes 반영 (사무실 qa video#2 순서)
1. 엄마 실루엣: 0~0.8초 불투명도 18%, 크기 1.0(평소 1.12), 위치를 문틀 쪽(x −2.05, 화면 x ≈ 0~100 CSS = 1080 기준 0~200)으로 옮겨 주인공 머리(화면 x ≈ 100~220)와 안 겹침. 문틀도 같은 자리로. 4.4초·9.2~11초·16.6~18초 엄마도 같은 문틀 위치 규칙.
2. 자막 vs 손가락: 폰을 협탁 위로 옮기고 버튼을 화면 위쪽으로 올려 버튼 아래 테두리·누르는 손끝이 자막 윗선(640)보다 30px 이상 위(≈ 605~610).
3. 팝 vs 얼굴·폰: 위 '배치 원칙'대로 장면마다 카메라 조정(0초·1.4·2.2·2.6·3.0 줌·4.4 클로즈업, 3.4·5.5~11 와이드, 11~16.6 앉은 장면, 16.6 엔딩 전 와이드). 비트별 정지 프레임 확인(제작-1).
4. 카운터 환산 15px의 근거: 제작과 정기 작업(매일 14:21) 지시문 2절 '화면 글자 가운데 정렬 (계정 주인 지시, 항상)'의 "카운터는 제목 바로 아래 가운데 한 줄(라벨 17px · 숫자 44~52px · 노란 서브 15px)". 계정 주인 고정 사양이라 그대로 따름.
5. 손·팔: 소매가 이불 오른쪽 앞 모서리에서 시작, 팔 길이 줄임(흰 소맷부리·손바닥·검지·엄지).
