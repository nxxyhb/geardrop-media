## video #3 반려 fixes 반영 (사무실 qa video#3 순서)
1. [자막↔폰] 폰 클로즈업 구간(0~3.4, 4.4~5.75, 12.9~13.9, 14.25~15.2초)에는 자막을 표시하지 않음(fix 1의 '자막을 빼거나' 선택). 내레이션 문장1(0.0~1.93)·문장2(2.15~5.08)는 소리로만, 문장5는 11.5~12.9초(앉은 장면)만 자막. 0초 글자 = 제목 + 카운터(라벨·숫자·환산) + 폰 버튼.
2. [폰 크기·위치] 0초·1.4~3.4초·4.4~5.75초 폰을 concept 배치표 크기로 키우고 가운데로: 화면 약 x 195~370 · y 520~870(CSS) = 1080 기준 x 390~740 · y 1040~1740, 버튼 글자 약 35px(=70px/1080), 버튼 약 y 640~700(=1280~1400). 폰 위 끝이 팝 아래 끝(≈490)보다 아래.
3. [손] 손을 폰 기준 좌표로 다시 만듦: 손등(구) + 손가락 마디 3개 + 위로 편 검지(손등에 붙음) + 엄지, 화면 아래에서 올라와 검지 끝이 버튼 아래 테두리를 실제로 누름(누를 때 버튼 6px 들어가고 그림자 사라짐). 흰 소맷부리(반투명 원판처럼 보이던 것) 삭제. 반전 클로즈업(14.25~15.2)에서도 같은 손이 왼쪽 아래에서 뻗어 와 14.6초에 누름.
4. [엄마 유령] 0~1.4초 엄마 실루엣을 뺌(fix 4의 '0초에서 빼기'). 4.4~5.75초 엄마는 문틀을 x −1.45로 옮겨 화면 왼쪽(머리 x ≈ 15~180 CSS, 몸은 주인공 머리 뒤)에서 불투명하게 또렷이.
5. [얼굴 어두움] 밤 장면(0~0.8, 4.4~5.75)에서 주인공에게 폰 빛 키 라이트(자체 발광 0.38) → 감은 눈·벌린 입·볼·까치집 머리 윤곽이 보임.
6. [카운터 환산] 크기 15px 유지 — 근거 원문: 제작과 정기 작업 지시(계정 주인이 저장한 매일 14:21 '③ 제작' 작업 프롬프트, 2026-11-21 실행분 포함) 2절 「화면 글자 가운데 정렬 (계정 주인 지시, 항상)」 "카운터는 제목 바로 아래 가운데 한 줄(라벨 17px · 숫자 44~52px · 노란 서브 15px)". 숫자와 붙던 문제는 환산 줄 위 여백 4px 추가로 해결(쉼표 꼬리와 안 닿음).
7. [경미] 벽 반투명 사각형(창빛 패치) 삭제 / 0~0.8초 폰 진동 + 0.0 누름 → 0.2 뗌 → 0.5 다시 누름 + 줌인(fov 32→30.8) / 4.4~5.75초 0초 구도 유지 후 5.75초 흰 플래시와 함께 와이드로 전환(밤→타임랩스) / 국자 '땡'은 엄마 손에서 바닥으로(4.5~4.75), 침대 위 우유팩·상자 3개 화면 오른쪽에 보임 / '되감는 중'·'누를 때마다 2배' 노란 글자 삭제(환산은 640분 이상에서만).
