# EP02 독립 검수 기록 (제작과)

매 회차 새 검수자(general-purpose 에이전트)에게 결과물(reel.mp4, concept.md)만 넘김.

## 1회 — 0초 프레임·첫 3초: PASS(수정 권장)
- 통과: 19.7초, 1080×1920, 오디오 있음, 두부·이모지 없음, 내레이션 0.0초 시작, 첫 사건 2.0초(2→4개), 첫 큰 확장 5.3초(1,024개).
- 지적: 0초 '1+1' 스티커가 작음 / 0초 배경에 편의점 없음 / 머리 위 김밥이 꽂힌 듯 보임 / 5.3초 김밥이 얼굴 관통 / 6.0초 주인공 안 보임 / (5.3초 자막 남음 → 실제 TTS가 5.8초까지라 유지)
- 조치: 0초 카메라를 편의점 간판이 보이게 옮기고 앞쪽 김밥 2개에 큰 1+1 스티커, 날아가는 김밥 출발점을 문 쪽으로, 실내 날아가는 김밥 경로를 주인공에서 비킴, 실내 김밥 더미 높이·주인공 위치 조정 후 재렌더.

## 2회 — 화면 구성: FIX
- 통과: 안전 영역(오른쪽 230px·y1440 아래 중요 글자 없음), 자막 겹침 없음, 카메라 벽 관통 없음.
- 지적: 11.8초 주인공이 거의 안 보이고 빨간 점 / 2.4초 클로즈업에서 두 얼굴 잘림 / 5.8·17.8초 제목이 주인공 머리를 덮음 / 17.8초 카운터가 봉투 스티커와 겹쳐 안 읽힘 / 15.5초 회색 막대(스캐너)가 알바생 얼굴을 가림.
- 조치: 11~12.6초 카메라를 꼭대기 주인공 추적으로 바꾸고 산 꼭대기 평평한 단면 버그(원뿔 윗반지름) 수정, 2.4초 줌아웃, 5.8·9.5·17.8초 카메라 시선 올려 주인공을 제목 아래로, 카운터에 반투명 어두운 판, 스캐너 제거, 반전 투샷 구도·주인공 단발 옆머리 축소 후 재렌더.

## 3회 — 글자 정확성: PASS
- 자막 6줄 대본과 일치, 배지 "만약에 EP02", 엔딩 카드 문구, 카운터 2^n 값·억/조 축약(10.7억, 1.1조 등) 모두 정확.
- 선택 수정 반영: 카운터를 14px 올려 자막과 간격 확보, 0초 카운터 보조문구 "멈추지 않는 중"으로 단축.

## 4회 — 소리: PASS
- 클리핑 없음(최대 -1.0dB), 효과음(펑 0.0·6.1초, 뿅, 삑 14.55초, 띵 18.2초) 화면과 일치, 반전 직전 정적 12.05~12.55초, 엔딩 페이드 정상, 자막 6줄 모두 말 시작 ±0.05초.
- 권장 반영: 통합 음량 -18.6 → -15.4 LUFS(loudnorm, 최대 -1.4dB), 배경음악 0.55→0.8배로 올림.
- 미반영: "2번 자막이 4.05초에 말 끝남" 지적은 문장 중간 쉼을 무음으로 잡은 것(합성 음성은 5.8초까지 이어짐)이라 자막 유지.

## 5회 — 처음 보는 시청자 관점: FIX
- 좋음: 0~4초 넘길 이유 없음(콜드 오픈→계산대→2초 첫 두 배→숫자 계속 증가), 알바생 대사 웃김.
- 지적: 14.5~17.2초 클로즈업 정지·카운터 1.1조에서 5초 멈춤 / 봉투 증식 0.6초뿐이라 반전 마무리가 안 읽힘 / 주인공 표정 그대로 / 루프 매치컷 불일치.
- 조치: 카운터가 반전 중에도 계속 증가(2.2조→4.4조), 알바생 샷 천천히 밀어 넣기, 16.5초 알바생 손의 봉투가 2개로 → 16.9초 주인공 얼굴 샷에서 봉투 4→8→16→32→64개로 얼굴을 덮음(약 2.1초), 표정 붕괴(눈 점·입 다묾·찡그린 눈썹·고개 흔들림), 엔딩 카드 18.6~19.9초, 총 19.9초. 매치컷은 마지막 화면이 1+1 스티커 클로즈업, 0초 화면도 큰 1+1 스티커가 있어 느슨하게 연결(정밀 매치는 생략). 효과음·띵 타이밍 이동 후 재렌더.

## 6회 — 최종 전체 점검: PASS
