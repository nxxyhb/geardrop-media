# EP03 영상 독립 검수 기록 (만약 꿈에서 모두가 나를 쳐다본다면?)

매 회차 새 검수 에이전트(제작 과정 모름, 결과물만 전달). 공통 체크: 길이 15~20초 / 1080×1920 / 오디오 / 두부·이모지 없음 / crop=880:1920:100:0 글자 안 잘림 / 치명적 문제.

## 1회 — 0초 프레임·첫 3초 → PASS (사소 6건)
- 공통 1~6 OK (19.5초, 1080×1920 30fps, AAC). 0초 썸네일(80억 명 + 외계인, UFO, 군중, 놀란 주인공) OK, 2.2초 할머니 흘끔·3.0초 2명·3.4초 4명, 5.0초 승강장 확장, 내레이션 0.02초부터 목소리.
- 사소: 0~0.6초 움직임 약함 / 1.5~1.8초 자막 '80억'과 카운터 '1명' 겹침 / 셀카 폰이 폰으로 안 읽힘·한 프레임에 같이 안 잡힘 / 창문 얼굴 수 적고 유리에 흐림 / 엔딩 때 카운터 사라짐 / 15.5초 화면 위 흰 띠(천장 조명).
- 반영(v2): 콜드 오픈 군중 고개 회전 폭 0.1→1, UFO 하강 시작, 입 더 크게, UFO 빛 원뿔(회색 삼각형처럼 보임) 제거 / 1번 자막을 '꿈에서 80억 명이'(0~1.0초)·'날 쳐다봐.'(1.0~2.1초)로 분할 / 폰에 분홍 케이스·화면·렌즈, 폰을 제목 영역 아래로, 셀카 컷을 외계인+주인공 투샷으로 / 창문 얼굴 48→88명, 유리 투명도 낮춤 / 엔딩 카드 동안 62명 카운터를 오른쪽 위로 작게 남김(x≤440 안) / 교실 카메라 높이 낮춤.
- 엔딩 카드 '다음 만약에는 내일 저녁 7시'는 팀 제작 규칙의 고정 문구라 유지(공유 CTA는 1개).

## 2회 — 화면 구성·안전 영역 → FIX
- 공통 1~6 OK. crop 상태에서 배지·제목·카운터·팝·자막·엔딩 카드 모두 온전, x≥880·y≥1440 글자 없음, 글자 겹침 없음.
- 고칠 점: 4.8~6.2초 승강장 컷에 주인공 없음 / 11.8~12.45초 셀카 뒤 외계인 눈 초근접이 안 보임 / 0.9초 되감기 카메라가 머리를 통과 / 16.0초 고개 돌릴 때 뒤통수 어색 / (사소) 17.8초 클로즈업 너무 가까움, 16.6초 창문 잠깐 빔, 2.0초 '처음엔' 두 번, 1번 자막 길이, 8.8초 카운터와 주인공 머리 붙음.
- 반영(v3): 승강장 카메라를 왼쪽 뒤로(주인공 뒷모습+열린 문+군중 한 화면) / 12.0~12.4초 외계인 눈으로 직선 줌(스냅 카메라) / 되감기 줌을 머리 앞 0.8에서 멈추고 1.0초 흰 플래시 / 고개 회전 83°→60° / 클로즈업 카메라 10% 뒤로 / 옆 반 얼굴 16.42초부터 등장 / 카운터 서브줄 '할머니 한 분' / 지구 줌아웃 시 주인공을 아래로.
- 유지: 1번 자막 종료(2.1초)는 실제 TTS 길이(2.04초)에 맞춘 것이라 그대로(기획의 1.8초는 예상치).

## 3회 — 글자 정확성 → PASS
- 공통 1~6 OK. 배지·제목·자막 9개·카운터 값 순서와 쉼표(16,384 / 16,777,216)·서브줄·팝 텍스트 16개·엔딩 카드 3줄 모두 기획 노트와 글자 단위 일치.
- 참고(사소, 미반영): 팝 텍스트 퇴장 때 한 프레임 작은 글씨 잔상 / 카운터 상승 중 중간값 노출(의도한 연출).

## 4회 — 소리 → FIX
- 공통 1~6 OK. 클리핑 없음(피크 -1.0dB), 자막-목소리 싱크 0.15초 이내, 덕킹 약 18dB, 효과음 타이밍 대체로 일치, 끝 페이드 OK.
- 고칠 점: 반전 직전 정적 0.3~0.4초뿐 / 5.0초 '두둥'이 내레이션 '두 배야'를 덮음 / (사소) 음량 -19.5 LUFS로 작음, 7.5초 저음 히트, 모노.
- 반영(v3 오디오): BGM·효과음을 11.95~12.82초 완전히 끊음(silencedetect -40dB 기준 정적 0.87초) / 두둥 -7dB·저역 위주로 깎음 / 음량 -15.9 LUFS(리미터 피크 -3.6dBFS) / 스테레오. 영상은 그대로, 오디오만 다시 합침.
